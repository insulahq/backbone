# CLAUDE.md — Security Boundaries

## Forbidden files — NEVER read these

The following files contain secrets, credentials, and server addresses.
**Do not read, cat, grep, or access these files under any circumstances:**

- `ansible/group_vars/all.yml` (passwords, API keys, domain config)
- `ansible/inventory/hosts.yml` (server IPs, hostnames)
- `ansible/.generated_secrets/` (all files in this directory)
- Any file matching `*.vault`, `*.key`, `*.pem` in the repo

Use the `.example` versions (`all.example.yml`, `hosts.example.yml`) for
understanding structure. Ask the user to run diagnostic commands and share
redacted output when debugging deployment issues.

## Secret generation

All secrets are generated by `ansible/setup.sh` which the user runs
directly — never generate, display, or suggest specific password values.
